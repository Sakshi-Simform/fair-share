# Fair Share

### Fair Share is a TypeScript-powered expense tracker that automatically splits group costs and tracks who owes what, with data saved in localStorage.

## Features :

- Add expenses with descriptions, amounts, and participants.
- Automatically calculate how much each person owes.
- View and track outstanding balances.
- Mark expenses as settled.
- Persist data using local storage.

## Tech Stack :

- HTML, CSS
- TypeScript
- Parcel, ESLint, Prettier
